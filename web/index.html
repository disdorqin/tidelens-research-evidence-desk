WHAT WE VERIFY

证据等级不能跳级

01 / DISCOVER发现原始来源

直接从 arXiv Atom API 获取论文标题、作者、时间和摘要，不依赖二次转载标题。

02 / TRACE保留可审计的证据

归一化官方链接、摘要 SHA-256、20 词以内的原文引句，避免复制整篇论文。

03 / EXPLAINAI 能力有边界

AI 总结只有在真实模型回答的引句与原文逐字匹配时展示。仍不代表其解释一定科学正确。

04 / REPRODUCE可复现实验流程

来源接口、解析器、回归测试和失败结果均可核验，展示数据有采集时间，不凭空生成论文。
